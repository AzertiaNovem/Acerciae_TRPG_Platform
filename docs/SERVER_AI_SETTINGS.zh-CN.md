# 服务器 AI 服务设置

服务器所有者和维护者可从侧栏齿轮进入“服务器设置 → AI 服务”，分别配置语言模型、图像生成和文字转语音。修改保存后生效，不需要重启。频道 KP 身份本身不授予维护者权限。

## 语言模型

API 协议可以选“OpenAI 兼容”或“Anthropic 兼容”。基础地址需包含 `/v1`，例如 `https://api.openai.com/v1` 或 `https://api.anthropic.com/v1`；使用中转服务时填写该服务提供的基础地址，不附加 `/chat/completions` 或 `/messages`。模型名填写服务商实际提供的模型 ID。

自定义协议和地址需配合本服务器自己的密钥。没有服务器密钥时，地址和协议沿用平台配置，平台密钥不会被送往维护者填写的其他地址。已有密钥不会返回浏览器；留空表示保留，勾选移除才会删除。

OpenAI 模式调用 Chat Completions；Anthropic 模式调用 Messages，支持多轮工具调用及 JSON 结果校验，原有知识权限检查继续生效。Anthropic 模式不发送 OpenAI 的 `reasoning_effort`，也不启用扩展思考参数。平台级向量检索仍是原来的独立设置，Anthropic Messages 不提供该项目的 embedding 调用。

## 独立的图像服务

图像服务可选择使用平台设置、关闭、Mock 测试图案或 GPT Image 兼容。GPT Image 模式使用自己的基础地址、密钥和图像模型，与文本模型及语音配置完全分开。即使三个服务来自同一家中转商，也需要分别明确配置。

模型 ID 不固定为某个版本；填写服务商实际支持的 GPT Image 兼容模型。尺寸可选服务商默认、1024×1024、1536×1024、1024×1536，质量可选默认、低、中、高。并非每个模型都支持全部参数，不确定时保持默认。

纯文字生成调用 `/images/generations`。提供参考图时，后端把已授权图片的真实内容作为文件提交到 `/images/edits`。请求不使用 GPT Image 不支持的旧 `response_format` 参数；返回须包含 `data[0].b64_json`。仅返回远程图片 URL 的旧接口不属于这个兼容模式。

配置 GPT Image 后仍需由 KP 在战役制作设置中允许云端处理，并由使用者确认本次发送的内容。关闭图像服务不影响已有图片和手动上传。更换地址、密钥、模型或图像参数时，尚未执行的旧任务会失败并提示重新提交；已经发出的请求可能完成。

## 用主立绘生成姿势图

进入角色空间的“外观与图片”，上传或生成主立绘，再选择生成模式及需要的表情或姿势，例如 `IDLE`、`SAY`、`SCARED`、`FIGHT`。已有主立绘时，可直接生成姿势图，不必重新填写一整套外貌描述。

姿势图以主立绘的实际图片为身份参考，要求保留脸部、发型、服装和画风，只调整姿态、表情及构图。系统记录参考资源 ID 和版本；后来替换主立绘不会改掉已完成图片的来源记录。图像模型的结果仍需人工检查。

一次选择生成主立绘及多个姿势时，姿势任务等待这次新主立绘完成，不会先拿旧图生成。主立绘失败或取消时，后续姿势任务也会失败，不会退回纯文字生成。视觉小说所需的姿势图遵守同一规则；缺少主立绘时，只有角色主人或 KP 能建立新的主立绘，其他作者需要先请他们准备好参考图。

## 测试范围

Mock 图像仍为明确标注的测试图案。本次自动检查用本地协议模拟服务验证了独立密钥、维护者权限、跨服务器隔离、Anthropic 工具往返、GPT Image 生成与参考图编辑、主立绘任务依赖、配置变更、限流重试及无效图片处理，没有使用真实付费服务凭据。

接口依据：[OpenAI 图片生成](https://developers.openai.com/api/reference/resources/images/methods/generate)、[参考图编辑](https://developers.openai.com/api/reference/resources/images/methods/edit)、[Anthropic Messages](https://platform.claude.com/docs/en/api/messages/create)。本实现使用 `anthropic-version: 2023-06-01` 作为兼容协议版本。
