# COC7 point-buy mode

A server feature (`features.coc7_points`, off by default; Server settings → Features → COC7 point-buy). While it is
on, every role card in the server is built the way the Call of Cthulhu 7e investigator sheet builds it:

- **Characteristics** show their accumulated total beside the heading (STR+CON+SIZ+DEX+APP+INT+POW+EDU; Luck apart).
- **Career points** come from the career's formula (教育×4, 教育×2＋力量或敏捷×2 …; "或" takes the better
  characteristic). They may only go to the career's own skills, the options the player picked from the career's choice
  groups ("聆听或侦查", "两项社交技能"), the player's free specialties (任意特长: skills of the player's choice, as many
  as the career grants) and Credit Rating.
- **Hobby points** are INT×2 and may go to any skill.
- A skill's total is base + growth + career + hobby. Bases are the 7e values (Dodge = DEX/2, Language (Own) = EDU,
  specialisations by family: Science 1, Art/Craft 5, Survival 10, Fighting (Sword) 20 …). No skill may pass 99, and
  Cthulhu Mythos takes no points. Credit Rating outside the career's range is a warning, not a block.
- A career that names a specialisation opens only that one: a doctor's "Science (Biology)" takes career points, their
  "Science (Chemistry)" does not; "any" entries (☆ 任意) open the whole family. Keys are read by their last
  parenthesis, so "Language (Other) (Latin)" belongs to Language (Other). Specialty slots keep their positions.
- Growth points record improvement (the Keeper's entry, or `.en` in chat): only the Keeper can change them; a player's
  save keeps the stored values.
- Some specialisations have their own base: Firearms (Rifle/Shotgun, 来复) 25, (SMG, 冲锋枪) 15, Bow 15, heavy
  weapons, machine guns and flamethrowers 10.
- When a card spells one skill twice ("侦查" and "Spot Hidden"), the dice get the higher value.
- The player can only choose a career from the built-in list. Custom career (自定义职业) is in the list: eight skills of
  the player's choice, credit rating agreed with the Keeper.

The server recomputes the totals on every save and refuses a card that breaks a limit (`400 points_rule` naming the
rule). The character space shows live counters, the ★ column of skills that may take career points, and the last
report's violations and warnings. The Keeper is held to the same rules in this mode; with the feature off, the card
takes skill totals directly as before and the stored career / point fields are kept but not enforced.

## The career list

`backend/src/characters/Coc7CareersData.cpp` is generated by `scripts/coc7_careers.py` from the community COC7 character
sheet workbook (*COC7 CY23 Plus*, sheets 职业列表 and 本职技能): 230 careers with credit-rating range, points formula,
fixed career skills, choice groups (☆ / ⊙ one of two, ☯ N social skills, ※ pick N) and the number of free specialties.
Careers 116–230 come from the Investigator's Companion, Japanese sourcebooks and 2010/2015 variants; the sheet marks them
"ask your Keeper first", and the description sentence shown under the career carries any such note. Skill names are
canonicalised with the dice alias table at startup (`会计` → `Accounting`, `格斗` → the Fighting family), so the same
names serve the card, `.ra` in chat and the visual novel.

`GET /api/coc7/rules` serves the skill table with bases, the specialisation families and every career to the client.

## Data on the card

```json
"career": { "name": "猎人", "choices": [["Survival (Sea)"], ["Listen"]], "specialties": [] },
"skill_points": { "Survival (Sea)": { "career": 20, "hobby": 0, "growth": 0 }, "Custom lore": { "career": 0, "hobby": 10, "growth": 0, "base": 5 } }
```

`choices[i]` holds the picks of the career's i-th option group; a family pick ("Survival") permits any specialisation of
it. `base` is only honoured for skills the table does not know. `skills` keeps the computed totals, and
`sheet.attrs` mirrors them for the dice.
