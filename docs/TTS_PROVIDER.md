# Speech providers and reproducible audio

Log Studio calls a C++ `TtsProvider`; it never calls a chat-completions endpoint for speech. The interface covers synthesis, preset voices, voice design/cloning, status, cost estimates, cancellation and capabilities. The non-streaming Qwen request is synchronous inside a PostgreSQL-backed asynchronous application job. Provider status therefore reports `n/a`; cancellation prevents pending work and attachment of cancelled results, but cannot undo an already billed HTTP request.

## Configure Qwen

Set `TTS_PROVIDER=qwen`, `QWEN_API_KEY`, and `QWEN_API_BASE` to the regional workspace host, for example `https://WORKSPACE.ap-southeast-1.maas.aliyuncs.com`. The key and workspace region must match. Server maintainers can instead configure an encrypted server TTS key/base/model in Server settings; those values override platform credentials for that server. The GM must enable Log Studio cloud processing under Library → Campaign production settings. The default is disabled. This switch applies to Studio TTS, image generation and performance suggestions; it does not change the existing background chronicler's settings.

Defaults are `qwen-audio-3.1-tts-plus` for production and `qwen-audio-3.1-tts-flash` for preset previews. A designed/cloned voice is previewed on its exact target model. Preset voice IDs are configurable with `QWEN_TTS_VOICES=id:name:language:gender,...`. The built-in subset is `longanhuan_v3.1`, `longanlingxin_v3.1`, `xunanchuan_v3.1`, `longanfengyue_v3.1`; availability must be checked for the configured model and region. A dialect is an instruction, not a guarantee of support.

The HTTP contracts were checked against Alibaba's [synthesis reference](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api), [voice customization](https://help.aliyun.com/zh/model-studio/voice-clone-design-http-api), [voice design](https://help.aliyun.com/zh/model-studio/voice-design-api-references) and [voice list](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list) on 2026-10-26. Live Qwen requests have not been validated with an account in this development environment.

Synthesis uses `/api/v1/services/audio/tts/SpeechSynthesizer` with `{model,input:{text,voice,format:"wav",language_hints?,instruction?,rate?,pitch?,volume?,sample_rate?,hot_fix?}}`. `speed` in application parameters maps to `rate`. Voice identity instruction and per-line delivery instruction are stored separately and combined only when requesting synthesis. Customization uses `/api/v1/services/audio/tts/customization`, model `voice-enrollment`, action `create_voice`, target model and an alphanumeric prefix. Design sends a description and preview text. Cloning sends a validated audio data URI and requires recorded consent, rights holder and statement. Returned voice IDs are stored; no local ID is substituted for a provider result.

## Dictionary and cache

Dictionary entries have `{term,reading,mode:"replace"|"phoneme",language}`. Replacement changes only the separately stored spoken text. With Qwen, phoneme entries become `hot_fix.pronunciation:[{"term":"pin1 yin1"}]`; providers without phoneme support use the supplied reading as a controlled replacement. The UI currently edits replacement entries; phoneme entries can be submitted through the API. Original dialogue remains unchanged.

Each cache key includes campaign, provider credential/endpoint namespace, profile ID/version, model, voice, actual spoken text, identity and delivery instructions, dictionary version, language and synthesis parameters. An advisory database lock coalesces simultaneous identical requests. Replaying an existing clip only downloads stored audio. A changed profile or line invalidates only matching lines. `force:true` rechecks/reattaches cached audio; it does not intentionally pay for duplicate identical synthesis.

Budget enforcement reserves Unicode character usage under a channel row lock before each uncached provider attempt. Failed/time-out attempts conservatively remain charged against this application budget because the vendor may have processed them. Cached hits cost zero. This is a character ceiling, not a billing ledger. `TTS_PRICE_PER_10K_CHARS` enables an approximate configured character-price estimate. Flash uses token billing; its estimate is explicitly unknown, not zero. Vendor usage is retained in audio provider metadata. Budget can be changed by the GM through `PUT /studio/settings`.

Jobs use pending/running/completed/failed/cancelled states, per-line retry limits, bounded concurrency (`TTS_CONCURRENCY`, default 2), provider timeouts, stale-job recovery and progress records. Submit `retry:true` to retry an identical failed/cancelled job. Audio is copied immediately from temporary vendor URLs into the configured object store; vendor URLs are never long-term playback addresses. Vendor audio download hosts are restricted and redirects are disabled. WAV duration is measured from bytes. No precise word timings are fabricated; the non-streaming player uses sentence-level synchronization.

`TTS_PROVIDER=mock` generates valid deterministic tone WAVs with `is_mock:true`, not synthetic human speech. `auto` falls back to this mode when no key is configured. Switching provider requires matching voice profiles. Local Qwen3-TTS is an extension point, not an implemented local inference service.
